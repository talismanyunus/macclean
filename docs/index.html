🔍How MacClean works

MacClean scans the home folder you select and shows you cleanable files — caches, logs, Xcode build artifacts, large old files, and more. Nothing is deleted until you review and confirm.

🔒Permissions

  • Home folder access — you choose your home folder once through the macOS file picker. Access is preserved across launches via a security-scoped bookmark.
  • Full Disk Access (non-App Store build) — needed only to inspect System Data areas like Application Support and Developer folders.
  • MacClean uses no network, no analytics, and no third-party SDKs.

Frequently Asked Questions

Why does MacClean need access to my home folder?
MacClean runs inside the macOS App Sandbox, which means it can only access folders you explicitly grant access to. You choose your home folder once — MacClean never accesses any other location.
Is it safe to clean Xcode build artifacts?
Yes. MacClean only removes DerivedData, CoreSimulator caches, and the Xcode cache folder. Your source code, projects, Git repositories, and Xcode Archives are never touched. Xcode will rebuild the removed artifacts on the next build.
Will cleaning caches slow down my apps?
The first launch of each app may be slightly slower after its cache is cleared, as the app rebuilds it. This is normal and expected — caches are designed to be regenerated.
Where do deleted files go?
Installer files and large personal files are moved to the Trash — you can recover them anytime before emptying the Trash. Caches, logs, and Xcode artifacts are permanently deleted after your explicit confirmation.
How do I revoke MacClean's folder access?
Open MacClean → click Privacy in the bottom-left sidebar card → tap Revoke access. The bookmark is deleted immediately and the app can no longer access your folders until you grant access again.
The app shows "System Data" is very large — why?
macOS includes protected system files, APFS snapshots, and virtual memory in its "System Data" figure. MacClean only shows the app-accessible portion (Application Support, Developer, Containers, Group Containers). These numbers will not match exactly.
Does MacClean read my messages or documents?
No. MacClean only reads file names, sizes, and modification dates. It does not open, read, or transmit the contents of any file. WhatsApp chat matching reads only the contact name and session type from the local SQLite database — message contents are never accessed.

🛡️Privacy Policy

Last updated: September 17, 2026

MacClean is a local macOS application that shows storage usage in the folders you select and deletes only the items you explicitly confirm.

Data collected and shared

MacClean does not send personal data, file contents, chat messages, or usage information to any server. The app contains no advertising, analytics SDKs, or third-party tracking tools.

Local file access

The app only accesses folders you select through the macOS file picker. This access is restricted by the App Sandbox. To retain access across launches, the app stores a macOS security-scoped bookmark in the app's local preferences. This bookmark does not contain file contents or directory listings.

Deletion

MacClean never deletes files automatically. Every deletion first shows you what will be affected and requires your explicit confirmation. Installer files and large personal files are moved to the Trash; caches, logs, and Xcode build artifacts are permanently deleted only after a separate confirmation.

Revoking access

You can revoke folder access at any time from Privacy › Revoke access inside the app.
